# TFA3 presentation guide

I continued my TSA1 Ledgerline Refill project, preserving its Today, All tasks, Profile, and About pages and its light/dark design. I added task, customer, and staff forms. Routes call controllers; controllers validate values and ask Models to save rows in the correct database. If a form is invalid, it shows the error and keeps what I typed. Tasks can be created, edited, and deleted. Staff can upload a JPG or PNG up to 2 MB. CodeIgniter prepares a 320 × 320 JPEG and stores only its filename in MySQL. The staff list displays that file or a placeholder. I also added a bottle-and-return logo image to the header.

I will demonstrate in this order: Today and the new logo; All tasks; create a task; edit its status; delete that test task; customer list; invalid and valid customer form; prefilled customer edit; staff list; duplicate username; prefilled user edit; invalid then valid avatar; resulting avatar on the list; `users.avatar` database value; mobile form; GitHub repository and both exports.

I will explain these terms simply: a **route** chooses the controller for a URL; a **controller** checks a request and saves it through a Model; a **Model** maps to a database table; a **view** renders escaped values; a **CSRF token** protects a POST form; a **thumbnail** is a prepared display copy. The task and POS data use separate databases because both contain a table named `users`.
